The T/R module: how each module's tolerances become the beam

An active electronically scanned array (AESA) is hundreds or thousands of identical transmit/receive (T/R) modules behind a grid of radiators. Each module amplifies, protects, attenuates and phase-shifts the signal for one element, and the beam is what they add up to. This page goes inside one module, then follows each of its datasheet lines out to the array: phase-shifter bits become gain loss and quantisation lobes, attenuator steps become the taper, module-to-module spread and temperature drift become the sidelobe floor, calibration pulls that floor back down, per-element power and noise figure add up to EIRP and G/T, isolation and switching time decide what the receiver survives and how close it can see, the scan angle changes the load on every PA, phase shifters squint the beam across a wide band, and heat and failed modules set how the array ages. Every term is defined before it is used, every step has worked numbers, and every chain is traced from your design choice to the system effect.

Step 0

What a T/R module is, and what is inside it

You already know

Every block inside a T/R module is a component you may have designed: a power amplifier (PA module), a low-noise amplifier (LNA module), a limiter and a circulator or T/R switch (limiter and duplexer module), and MMIC switches, phase shifters and step attenuators. From the antenna page, Step 6, you know that an array steers its beam by giving element n the phase −360°·(d/λ)·n·sin θ0, and that random phase errors lose gain as exp(−σ²) and raise the sidelobes. This page does not repeat those pages; it shows what happens when a thousand of these blocks have to act as one.

Definitions

Element: one radiator of the array (a patch, a dipole, a notch). Element spacing d: the distance between neighbouring elements, usually about λ/2 at the highest frequency.

Phased array: an antenna made of many elements whose signals are added with chosen phases, so that the beam can be pointed without moving anything. Passive array: one big transmitter and receiver feed all elements through phase shifters. Active array (AESA): every element has its own T/R module with its own PA and LNA.

T/R module: the electronics behind one element (or a few). It contains a transmit path, a receive path, a shared common leg that holds the phase shifter and attenuator, and control logic.

Beamformer (manifold): the passive network that splits the transmit drive to all modules and adds all received signals together. In a digital array the receive adding is done in numbers after an ADC per element or per group.

Circulator: a three-port ferrite device that passes power one way round: PA → antenna → receiver. T/R switch: a switch that connects either the transmit or the receive path to the common leg (or to the antenna). Duplexing is the general word for sharing one antenna port between transmit and receive.

Control: the logic that receives the beam-steering command (a phase and an attenuation number for this module), latches it at the right moment, switches between transmit and receive, pulses the PA bias, and reads a temperature sensor.

The diagram shows the most common layout. Read it in transmit first: the beamformer delivers a small drive signal (about 0 dBm) to the module. It passes the attenuator and phase shifter in the common leg, the common-leg T/R switch sends it to the transmit path, a driver and the PA raise it to the module output (10 W here), and the circulator passes it to the radiator. In receive, the echo enters from the radiator, the circulator sends it to the receive path, the limiter protects the LNA, the LNA amplifies it, and the same T/R switch, attenuator and phase shifter pass it back to the beamformer. The phase shifter and attenuator are used twice, once in each direction, which is why they sit in the common leg.

What goes wrong with the naive view: "a T/R module is a PA plus an LNA"

If you look at one module alone, the PA and LNA are the hard parts and the rest is plumbing. In the array the plumbing decides the beam. Three numbers from later steps show it. A 3-bit phase shifter loses only 0.22 dB of gain, but its rounding pattern puts a discrete lobe at −17 dB in a −35 dB design (Step 2). A module-to-module spread of 10° and 1 dB, which nobody would notice on a single module, lifts the sidelobe floor of a 64-element array to −31 dB (Step 4). And a T/R switch that takes 1 µs to settle makes the radar blind out to 150 m beyond the pulse itself (Step 7). None of these show up on a single-module test; all of them are set by single-module design choices.

How the common leg is placed, and why

The phase shifter and attenuator lose 6–10 dB together. On transmit they sit before the driver, where the signal is a milliwatt, so that loss costs only a few dB more driver gain instead of 10 W of PA output. On receive they sit after the LNA, so that the LNA's 25 dB of gain makes their loss almost invisible in the noise figure (Step 6 shows the numbers: 2.8 dB module noise figure with the loss after the LNA, nearly 14 dB with it before). The circulator and limiter, which must be in front of the LNA, are kept as low-loss as possible because every 0.1 dB there costs 0.1 dB of both EIRP and G/T.

Check yourself

Why can one phase shifter serve both transmit and receive?

A passive phase shifter is reciprocal: it gives the same phase in both directions. Steering needs the same phase on transmit and receive (the beam points the same way), so one common-leg device, switched between the Tx and Rx paths, does both jobs and halves the parts count. If transmit and receive must point differently at the same time, the module needs separate phase shifters per path.

Step 1

Phase shifters: types, bits and quantisation error

You already know

Antenna Step 6: element n needs phase −360°·(d/λ)·n·sin θ0; with d = λ/2 and θ0 = 30° the step between neighbours is 90°. A random phase error of σ radians rms keeps a fraction exp(−σ²) of the gain in the beam (the Ruze relation).

Definitions

Digital phase shifter, k bits: a device with 2k phase states, built from k switched sections of 180°, 90°, 45°, 22.5°, 11.25° and 5.625°. LSB (least significant bit): the smallest step, 360°/2k.

Quantisation error: the difference between the phase the beam needs at an element and the nearest state the shifter can make. It lies between −LSB/2 and +LSB/2.

rms (root mean square) error σ: the square root of the average of the squared errors over all elements. A uniformly spread error between ±LSB/2 has rms LSB/√12.

State error (device error): how far each real state is from its nominal value, measured on a network analyser over all 2k states; datasheets give it as "rms phase error". Amplitude variation over states: how much the insertion loss changes from state to state.

Insertion loss (IL): the loss through the device in its reference state. Switching time: the time from a new command to the phase settling, set by the switch technology and drivers.

A phase shifter cannot make any phase, only one of its 2k states. Every element therefore gets the nearest state, and the leftover quantisation error acts on the beam exactly like the random phase error of antenna Step 6, as long as it looks random across the array (Step 2 shows when it does not). The real device adds its own state error on top. The two are independent, so their squares add.

σq = LSB/√12 = 360°/(2k·√12)    σ = √(σq² + σdev²)    gain kept ≈ exp(−σ²), σ in radians4 bits: LSB 22.5°, σq = 6.50° = 0.113 rad, exp(−0.0129) = 0.987, a gain loss of 0.056 dB. Add a 2.5° device error: σ = √(6.5² + 2.5²) = 7.0°, loss 0.065 dB. The loss applies on transmit and again on receive.

What goes wrong with the naive approach

Two naive choices fail in opposite directions. Fewest bits, because each bit costs about 1 dB of loss and die area: a 2-bit shifter (180° and 90°) has LSB 90° and σq = 26°, so the array loses 0.89 dB on transmit and again on receive, 1.8 dB of radar sensitivity, before Step 2's lobes. Most bits, because finer must be better: going from 4 to 6 bits cuts σq from 6.5° to 1.6°, but with a 2.5° device error the total only falls from 7.0° to 3.2°, the gain improves by 0.05 dB, and the insertion loss rises from 4.1 to 5.9 dB. Below about σq ≈ σdev, more bits buy nothing.

The insertion loss is modelled as a fixed part plus a loss per bit (for example 0.5 + 0.9·k dB for high-pass/low-pass). In an AESA the shifter sits in the low-power common leg, so its loss costs driver and LNA gain, not transmit power or noise figure (Step 6). The ferrite's low loss and high power make it the choice for a passive array, where one shifter per element sits after the big transmitter; its 2 µs switching time limits how fast the beam can hop (Step 7). The vector modulator makes amplitude and phase at once from two DAC words, which saves the separate attenuator, but it only reaches its accuracy through a calibration table (Step 5).

How to choose the number of bits and the type

(1) Take the phase-error budget σ from the sidelobe and gain requirements (Step 4 shows how a budget is split). (2) Choose k so that the quantisation part is no bigger than the device part: σq ≤ σdev gives 2k ≥ 360°/(√12·σdev). With σdev = 2.5°: 2k ≥ 41.6, so k = 6 (5 bits leaves σq = 3.2° > 2.5°). (3) Check the lobe rule of Step 2: with round-to-nearest the worst lobe is about 1/22k, so −30 dB sidelobes need 5 bits or decorrelated rounding. (4) Pick the type by bandwidth, loss, power and switching time. More bits lower σq by half per bit and add about 1 dB of loss; a type with lower state error makes the extra bits worth having.

Step 2

Quantisation lobes, and why randomised rounding removes them

You already know

Step 1: the rms quantisation error σq = LSB/√12 costs gain as exp(−σ²). Antenna Step 6: a random phase error spreads the lost power into a broad floor. A periodic error does something different: a grating with a regular period sends power into discrete directions, like a diffraction grating.

Definitions

Periodic error: an error that repeats in a regular pattern across the aperture. Quantisation lobe: a discrete sidelobe created by a periodic quantisation error.

Taper used on this bench: a fixed −35 dB Taylor taper. The edge elements are driven 15.7 dB weaker than the centre, which pushes the array's own sidelobes down to −35 dB so that small lobes become visible. How a taper is made with attenuators is Step 3; here it is fixed.

Peak sidelobe level (PSL): the highest lobe outside the main beam, in dB relative to the main-beam peak. Average error floor: the mean level of the scattered power, σ²/(ηt·N), where ηt is the taper efficiency (0.808 for this taper, Step 3) and N the number of elements.

Round to nearest: every element gets the state nearest to its required phase. Random phase offset: each element has a fixed, known extra phase φr,n (for example its own measured insertion phase, which is random anyway); the controller rounds φn + φr,n and the hardware path removes φr,n. Probabilistic rounding: round up with a probability equal to the fractional part of φn/LSB, otherwise down.

The required phase φn = −360°·(d/λ)·n·sin θ0 grows by the same step from element to element. With round-to-nearest the error is a sawtooth function of φn, and because φn is a straight line in n, the error repeats across the aperture with a regular period. A periodic phase error is a phase grating: it puts a fraction of the power into discrete lobes instead of a floor. Mailloux gives the worst-case level of that lobe as about 1/22k. The key difference from a random error: the lobe level does not depend on N. A bigger array lowers a random floor; it does nothing to a quantisation lobe.

periodic (round to nearest): PQL ≈ 1/22k    random: floor ≈ σ²/(ηt·N)3 bits: 1/64 = −18 dB; 4 bits: −24 dB; 5 bits: −30 dB. If the same 3-bit error were random, the floor for N = 128 would be (0.227 rad)²/(0.808 × 128) = −33 dB, and the highest of the random peaks lands typically 5–10 dB above the average floor.

What goes wrong with the naive approach

The naive beam-steering computer rounds every element to the nearest state. For 128 elements, 3 bits and θ0 = 20°, the rms error is 13°, the gain loss 0.22 dB, and Step 1 would call that acceptable. The pattern says otherwise: a single lobe at −23.25° reaches −16.9 dB, 18 dB above the −35 dB the taper was designed for. A jammer in that direction gets in 18 dB more easily than the specification promised.

How to choose the rounding method and the bits

(1) Compare 1/22k with the peak-sidelobe requirement. If the lobe is below it, round to nearest is fine. (2) If not, either add bits (each bit lowers the lobe by 6 dB and adds about 1 dB of loss) or decorrelate. (3) The random-offset method is nearly free: every module already has a random insertion phase that calibration measures (Step 5); the controller simply rounds after adding the module's own measured phase instead of after removing it. (4) After decorrelation the residual is σ²/(ηt·N): it falls 3 dB each time N doubles, so large arrays tolerate fewer bits than small ones. (5) Probabilistic rounding needs no stored offsets but changes the pattern at every beam update, which some tracking and clutter-cancelling modes dislike.

Step 3

Attenuator steps and the amplitude taper

You already know

Antenna Step 5: a uniformly driven aperture has a first sidelobe of −13.3 dB. Driving the edges weaker than the centre (a taper) lowers the sidelobes, widens the beam a little and costs some gain. You have designed or measured digital step attenuators: switched T or π pads in binary steps.

Definitions

Amplitude taper: the set of relative amplitudes wn given to the elements. Taylor taper (n̄ = 5): a standard taper that holds the first few sidelobes at a chosen design level and lets the far ones fall; "−35 dB Taylor" means the first sidelobes are at −35 dB.

Taper efficiency ηt: the gain of the tapered array divided by the gain of the same array driven uniformly: ηt = (Σwn)²/(N·Σwn²).

Digital step attenuator, b bits with step LSB: attenuation states 0, LSB, 2·LSB … up to the range LSB·(2b − 1). Amplitude quantisation error: the difference between the attenuation wanted and the nearest step, uniform within ±LSB/2, rms LSB/√12. Clipping: when an element needs more attenuation than the range, it gets the maximum instead.

Insertion phase versus attenuation state: a real attenuator changes its phase slightly from state to state, given here in degrees per dB of attenuation.

In receive, the attenuator in each module sets that element's weight, so the taper is simply a table of attenuation values. For a 64-element −35 dB Taylor taper the centre elements get 0 dB and the edge elements 15.74 dB. The attenuator then approximates each value with its nearest step. The step error is an amplitude error, and like the phase error of Step 1 it adds to the floor of Step 4. If the range is too small, the edge elements are clipped and the taper flattens towards uniform, which brings the high sidelobes back.

range = LSB·(2b − 1)    σa = LSB/√12 (dB)    σa,lin = 0.115·σa,dB    ηt = (Σw)²/(N·Σw²)6 bits × 0.5 dB: range 31.5 dB, σa = 0.144 dB (the bench measures 0.129 dB on this taper). −35 dB Taylor, N = 64: ηt = 0.808, a gain cost of 0.93 dB that is paid on purpose for the low sidelobes.

What goes wrong with the naive approach

Two naive choices. A short attenuator, sized only for gain trimming: 3 bits × 0.5 dB gives 3.5 dB of range, so 34 of 64 elements are clipped, ηt rises to 0.973 (the taper is almost gone) and the peak sidelobe is −17.0 dB instead of −35. Coarse steps to save bits: a 2 dB LSB leaves a 0.55 dB rms amplitude error and the peak sidelobe rises to −31.8 dB. Neither shows on a single-module test.

A transmit note. On transmit the PAs run in saturation for efficiency, and a saturated PA ignores a small drive change, so the attenuator cannot taper the transmit beam. Most AESAs transmit uniformly (ηt = 1, −13 dB sidelobes) and taper only on receive. A transmit taper needs PAs of different sizes, different supply voltages or backed-off PAs (with poorer efficiency, Step 10).

How to choose the attenuator range, step and phase flatness

(1) Range ≥ edge attenuation of the lowest-sidelobe taper + the module-to-module gain spread to be trimmed + the temperature compensation. For −35 dB: 15.7 + about 3 dB (±1.5 dB spread) + about 2 dB (temperature) ≈ 21 dB, so 6 bits × 0.5 dB (31.5 dB) with margin, 5 bits × 0.5 dB (15.5 dB) not. (2) Step: σa = LSB/√12 must be a small part of the amplitude budget of Step 4; 0.5 dB gives 0.14 dB. (3) Phase change per dB: every attenuation change also shifts the phase. If the calibration table corrects the phase command for each attenuator state (Step 5), a few degrees per dB is harmless; if not, keep it below about 1°/dB. (4) A lower sidelobe target costs gain on every target (0.93 dB at −35, 1.33 dB at −45) and needs smaller random errors, so do not ask for more taper than the system needs.

Step 4

Amplitude and phase errors across modules and over temperature

You already know

Steps 1–3: quantisation and attenuator steps leave errors that act on the beam. Antenna Step 6: random errors keep exp(−σ²) of the gain and scatter the rest into a floor. Here the errors come from the modules themselves: no two MMICs, bond wires and lines are identical, and they drift with temperature.

Definitions

Random phase error σφ: the rms spread of insertion phase between modules, after the commanded phase is set. Random amplitude error σa: the rms spread of gain between modules, in dB.

Common-mode drift: the change that all modules share (the average module gets 0.5° more phase and 0.015 dB less gain per °C, for example). It does not change the pattern shape, only the overall gain.

Tracking: how closely modules follow each other over temperature, given as the rms module-to-module spread of the drift, for example 0.1°/°C and 0.01 dB/°C. This spread grows with the distance from the calibration temperature.

Error floor: the average sidelobe level caused by random errors, relative to the error-free peak. Calibration temperature: the temperature at which the errors were measured and removed (25 °C here; Step 5).

A module has both an amplitude and a phase error, and both move part of the signal out of the beam. Writing the module's complex weight as (1 + an)·ejφn with small random an and φn, the scattered power is proportional to σa² + σφ² (amplitude as a fraction, phase in radians). It spreads over all angles, so per direction it is divided by the number of elements and weighted by the taper. Temperature adds the tracking spread times the distance from the calibration temperature, independently of the static spread.

G/G0 = exp(−σφ²)/(1 + σa²)    floor = (σa² + σφ²)/(ηt·N)    σ(T) = √(σ0² + (c·|T − 25 °C|)²)N = 64, −35 dB taper (ηt = 0.808), 5° and 0.5 dB: σφ = 0.0873 rad, σa = 0.115 × 0.5 = 0.0576; σ² = 0.00762 + 0.00332 = 0.0109; floor = 0.0109/51.7 = 2.1×10−4 = −36.7 dB. Gain loss only 0.05 dB. The highest random lobe usually lands 5–10 dB above the floor: the bench shows −27.3 dB.

What goes wrong with the naive approach

The naive check looks only at gain. Modules straight from production typically spread 10° and 1 dB; the gain loss is just 0.19 dB, so the array "works". But the floor for 64 elements is −30.7 dB and the peak sidelobe −22.9 dB: the −35 dB taper of Step 3, and the 0.93 dB of gain paid for it, are wasted. The second naive check is done at 25 °C only. With typical tracking (0.1°/°C, 0.01 dB/°C), a perfectly calibrated array at 85 °C already has 6° and 0.6 dB of spread: floor −35.2 dB, peak about −26 dB.

Step 5

Calibration: removing the module errors, and keeping them removed

You already know

Step 4: a raw spread of 10° and 1 dB gives a −31 dB floor on 64 elements, and temperature adds spread. On the bench you correct a measurement by subtracting a known error (de-embedding). Array calibration is the same idea applied to every module.

Definitions

Calibration: measuring each module's amplitude and phase error and storing a correction, so that the commanded phase and attenuation include it. Calibration table: the stored corrections, per module, and often per frequency, per temperature and per state.

Factory calibration: measured once on a near-field scanner or test range. Near-field scanner: a probe moved over a plane in front of the array that measures the field of each element. REV method (rotating element electric vector): step one element's phase through all states while watching the total power; the shape of the power change gives that element's amplitude and phase.

Built-in calibration: a coupler network (or the mutual coupling between neighbours) that injects or picks up a reference signal at each module in service, so the table can be refreshed without a range.

Residual error: what is left after calibration: the measurement accuracy, plus whatever drifted since the measurement.

Calibration does not make the modules identical; it makes the commands different so that the outputs become identical. The quality of that is limited by how well the errors are measured and by how much they change afterwards. A table measured at 25 °C stops being valid as the temperature moves, by the tracking spread of Step 4. A table with entries every 20 °C, read with the module's own temperature sensor, leaves only the curvature between points. A built-in loop can be re-run in service, so temperature and ageing drop out, but it is limited by how well its own coupler network tracks.

σafter = √(σmeas² + σdrift²)    σdrift = c·|T − Tcal| (single-point table)Accuracy 1°, 0.1 dB, typical tracking 0.1°/°C: at 25 °C σφ = 1.0°, floor −50.7 dB; at 70 °C σφ = √(1² + 4.5²) = 4.6°, floor −37.5 dB. The over-temperature table is modelled with a quarter of the drift between its 20 °C points; the built-in loop with an extra 1.5° and 0.15 dB from its coupler network.

Step 6

Per-element transmit power and noise figure, and how they add up to EIRP and G/T

You already know

Antenna page: EIRP = P·G and G/T = gain over system noise temperature. LNA module: the Friis formula, and that loss in front of the LNA adds directly to the noise figure. The radar equation: the received signal-to-noise ratio grows with Pt·Gt·Gr/Tsys, that is with EIRP × G/T.

Definitions

Element gain Gel: the gain of one element in the array, set by the area it occupies: Gel = 4π·Acell/λ² = π (4.97 dBi) for a λ/2 × λ/2 cell, falling as cos θ with scan because the aperture looks smaller from the side.

Coherent combining: when N signals add in phase, their voltages add, so the power goes as N². Array gain: G = N·Gel.

EIRP of the array: N PAs each radiating Pel/Lf, times the array gain: EIRP = N·(Pel/Lf)·N·Gel. Lf: the front-end loss between the PA or LNA and the radiator (circulator, limiter, lines), here the same on both paths.

Tsys per element: the noise temperature at the element: antenna temperature Ta (290 K here) + loss noise (Lf − 1)·290 K + Lf·TLNA, with TLNA = 290·(F − 1). Because each element's noise is independent, noise powers add as N while signals add as N², so the array's G/T = N·Gel/Tsys.

This is the step where component numbers turn directly into the system's headline figures. On transmit, N PAs in phase put N² times one PA's power density on the target: double the element power and EIRP rises 3 dB; double the number of elements and it rises 6 dB (twice the power, twice the gain). On receive, the signal adds coherently and the noise does not, so G/T rises 3 dB per doubling of N, and depends on the element NF exactly as a single receiver does. The radar product EIRP·G/T therefore grows as N³: 9 dB per doubling.

EIRP = N²·Pel·Gel/Lf    G/T = N·Gel/[Ta + (Lf − 1)·290 + Lf·TLNA]N = 1024, 10 W, Lf = 1 dB, NF 2.5 dB, broadside: G = 1024π = 35.1 dBi; radiated 1024 × 10/1.26 = 8.13 kW; EIRP = 39.1 + 35.1 = 74.2 dBW. TLNA = 226 K, Tsys = 290 + 75 + 284 = 649 K (28.1 dBK); G/T = 35.1 − 28.1 = 7.0 dB/K.

Put the lossy parts anywhere. Move the 11 dB common leg (phase shifter, attenuator, switch) in front of the LNA: with 0.9 dB of circulator and limiter loss already there, the loss before the LNA becomes 11.9 dB, Tsys rises from 542 K to 6 840 K and G/T falls by 11 dB, the same as losing 92 % of the elements. The common leg after the LNA still adds noise divided by the LNA gain: with 25 dB of LNA gain the module NF is 2.80 dB, with only 15 dB it is 3.64 dB. The LNA gain must exceed the common-leg loss by 10 dB or more.

Step 7

Isolation and switching time: what the receiver survives and how close it can see

You already know

Limiter and duplexer module: a circulator has finite isolation, a limiter has a power rating, flat leakage and a recovery time. PA module: a biased PA amplifies its own input noise even with no drive.

Definitions

Circulator isolation I: how much weaker the PA power is at the receive port than at the antenna port (20 dB typical for a small module circulator). Antenna return loss RL: how much of the power reaching the radiator is reflected back; the circulator sends the reflection straight into the receive path. In an array RL changes with scan (Step 8).

Worst case (in phase): the leakage and the reflection add as voltages: P = PPA·(10−I/20 + 10−RL/20)². Average (random phase): they add as powers.

PA gating: switching the PA's drain or gate bias off outside the transmit pulse. A biased PA with no drive still delivers kT·F·G of noise at its output.

T/R switching time tsw: the time from the end of the pulse until the receiver is usable: PA bias off, switches settled, limiter recovered. Blind range: the range within which echoes arrive before the receiver is ready: Rmin = c·(τ + tsw)/2, τ the pulse width. Beam switching time: the time for new phase and attenuator words to settle (Step 1 types).

During the pulse, the receive path is not disconnected from the PA, only isolated from it. Two paths bring PA power to the limiter: leakage through the circulator and reflection from the radiator. Between pulses, the receive path listens through the same circulator, so anything the PA emits then, including its own amplified noise, reaches the LNA attenuated only by the isolation. And because the module must change between the two states, the time it takes is time when the radar cannot hear.

A biased PA with 30 dB gain and 6 dB NF: −138 dBm/Hz at its output, −158 dBm/Hz into the receiver, 16 dB above kT. τ = 1 µs, tsw = 200 ns: Rmin = 180 m.

What goes wrong with the naive approach

"The circulator isolates 20 dB, so the receiver sees 23 dBm." That ignores the reflection. At a scan angle where the active return loss falls to 6 dB (Step 8), the reflection alone is 37 dBm, and the worst case is 38.6 dBm, 7.2 W into a limiter rated 5 W. "The PA is not driven between pulses, so it is quiet." Left biased, its output noise reaches the receiver 16 dB above kT: a noise temperature of 11 500 K against a 580 K receiver, a 13.2 dB loss of sensitivity, far more than any LNA improvement could recover.

Step 8

Scan-dependent active impedance, and what it does to the PA

You already know

Antenna Step 2: the reflection coefficient Γ, VSWR = (1 + |Γ|)/(1 − |Γ|), and mismatch loss 1 − |Γ|². PA module: a PA's output power and efficiency depend on the load it sees, which is why it is designed at an optimum load found by load-pull.

Definitions

Mutual coupling Sm: the fraction of the wave leaving one element that arrives at the element m places away (an S-parameter of the array, Sn,n+m).

Active reflection coefficient Γa(θ): the total wave coming back into one element's port when all elements are driven with the steering phases for angle θ: its own reflection S11 plus everything its neighbours couple into it, each with the neighbour's phase. Active VSWR: the VSWR that goes with |Γa|.

Grating-lobe onset: the scan angle at which a second full beam enters real space, sin θg = λ/d − 1. Scan blindness: an angle where |Γa| approaches 1 and the array radiates almost nothing, usually just before the grating-lobe onset, when a surface wave along the array is in step with the steering phase.

Load-line (Cripps) model: a PA limited by its maximum current and maximum voltage swing delivers its full power only into its optimum load Ropt; into a lower |Z| it is current-limited (P/Popt = R/Ropt), into a higher |Z| voltage-limited (P/Popt = R·Ropt/|Z|²).

An element measured alone, or in an array with only its own port driven, shows S11. In operation every neighbour is driven too, and part of each neighbour's signal couples back into this element's port with a phase that depends on the steering. At broadside the neighbours are in phase and the designer matches the element in that condition. As the beam scans, the coupled waves rotate in phase relative to each other and stop cancelling, so Γa grows, and every PA in the array sees the same new load at the same moment. With a circulator, the reflected power goes into the circulator's load resistor (and towards the receiver, Step 7) and the PA sees a good match. Without one (a switch-based module), the PA itself sees the active VSWR.

What goes wrong with the naive approach

The naive design matches the radiator on its own (or at broadside) and assumes it stays matched. Step 9

True time delay versus phase shift: beam squint over a wide band

You already know

Antenna Step 7: a phase-steered array points to sin θ(f) = (f0/f)·sin θ0, so the beam squints by Δθ ≈ −(Δf/f0)·tan θ0; true time delay removes it. Step 1 here: a switched-line shifter is really a delay, while a high-pass/low-pass shifter gives a flat phase.

Definitions

Phase shift: a fixed phase that is the same at all frequencies (modulo 360°). True time delay (TTD): a delay τn = xn·sin θ0/c, whose phase 2π·f·τn grows with frequency, exactly as the path difference to the target does.

Beam squint: the change of beam direction with frequency in a phase-steered array. Instantaneous bandwidth (IBW): the band the array can use at once (one chirp, one wideband jamming signal) without the band edges losing too much gain.

Beamwidth θ3: 0.886·λ/(L·cos θ0) radians for a uniform aperture of length L. Aperture fill time: Tfill = L·sin θ0/c, the time a wavefront takes to cross the aperture at θ0, which is also the largest delay a TTD array needs.

Subarray TTD: elements grouped into subarrays of M; a delay per subarray, phase shifters inside it.

The steering phase is meant to cancel the path difference xn·sin θ0 to the target. That path difference is a time, so the phase it needs is proportional to frequency. A phase shifter sets the right phase at f0 only; above f0 the phase is too small for the actual path, and the beam points closer to broadside, below f0 further away. When the squint at the band edge becomes comparable with the beamwidth, the band edges point past the target. Delay lines (TTD) make the phase scale with frequency and remove the squint, at the cost of long, lossy delay lines up to Tfill. Subarray TTD is the usual compromise: each subarray of M elements has a beam N/M times wider than the full array, so it tolerates N/M times more squint.

Δθ ≈ −(Δf/f0)·tan θ0    θ3 = 0.886·λ/(L·cos θ0)    IBW (phase shifters) ≈ θ3/tan θ0    Tfill = L·sin θ0/c64 elements at λ/2 (L = 32 λ), θ0 = 30°: θ3 = 0.0320 rad = 1.83°; IBW ≈ 0.0320/0.577 = 5.5 %. A 10 % band (±5 %) squints by ±1.65°, nearly a full beamwidth. At 10 GHz L = 0.96 m and Tfill = 1.6 ns.

What goes wrong with the naive approach

A narrowband design is reused for a wideband waveform: phase shifters in every module, a 1 GHz chirp at 10 GHz (10 %), beam steered to 30°. The centre of the chirp hits the target; the band edges point to 31.75° and 28.4°, and their gain towards the target falls by 12.6 dB. After pulse compression the range response loses its edges, widens and its sidelobes rise; for a wideband jammer, the edges of its band go to the wrong place.

(5) A digital array with an ADC per subarray can apply the delays in the processor instead of in hardware.

Step 10

Thermal design: heat per module, junction temperature and life

You already know

PA module: power-added efficiency PAE = (Pout − Pin)/PDC, the power that is not radiated becomes heat, and the junction temperature is the cold-side temperature plus thermal resistance times dissipated power. Reliability of semiconductors follows the Arrhenius law: life falls exponentially with temperature.

Definitions

Duty cycle: the fraction of time the PA transmits (pulse width × repetition frequency). Peak and average dissipation: heat during the pulse, Ppk·(1/PAE − 1), and its average, duty × peak.

Thermal resistance θ: °C rise per watt from the junction to the cold plate, through the die, die attach, carrier, package and interface material. Thermal time constant: how quickly the die heats up during a pulse; modelled here as 200 µs for 60 % of θ (the die and attach); the rest of the path only sees the average.

Cold plate: the liquid- or air-cooled surface the modules are mounted on. Design limit Tj,max: the junction temperature the design must not exceed (175 °C here, illustrative for GaN with derating).

MTTF: mean time to failure. Arrhenius law: MTTF = MTTFref·exp[(Ea/k)·(1/Tj − 1/Tref)], with activation energy Ea (1.0 eV here) and MTTFref = 106 h at 200 °C (illustrative); near 150 °C life roughly halves for every 10 °C.

An array is a dense heater. Each module turns DC power into RF at the PAE and the rest into heat in a few square millimetres of GaN, with thousands of modules on one cold plate. Two temperatures matter: the average, which the cooling system and the cold plate set, and the peak at the end of each pulse, which the die and its attach set. Short pulses are averaged by the die's thermal mass; long pulses heat the junction almost as if the PA were on continuously. The junction temperature sets the PA's life, and the temperature differences across the array feed the tracking errors of Step 4.

Qpk = Ppk·(1/PAE − 1)    Tj,avg = Tcp + θ·duty·Qpk    Tj,pk = Tj,avg + 0.6·θ·(Qpk − Qavg)·(1 − e−τ/200 µs)10 W peak, PAE 35 %, 15 % duty, 100 µs pulses, θ = 4 °C/W, cold plate 50 °C: Qpk = 18.57 W, Qavg = 2.79 W; Tj,avg = 61.1 °C; Tj,pk = 61.1 + 2.4 × 15.8 × 0.393 = 76.0 °C. Module DC input 4.89 W (including 0.6 W for the receive chain and control), heat 3.39 W; 1024 modules: 3.47 kW of heat.

What goes wrong with the naive approach

The naive thermal design uses the average dissipation only. For a long-range mode (20 W, PAE 30 %, 30 % duty, 500 µs pulses) the average junction is a comfortable 106 °C, but at the end of every pulse it reaches 178 °C, over the 175 °C limit, and the life at that peak is 3.3 × 106 h instead of the 4 × 108 h the average suggests. The other naive step is to treat PAE as a PA-only figure: at 20 % instead of 35 % the array's heat rises from 3.47 kW to 6.76 kW, which the cooling system and the power supply both have to carry.

Step 11

Failure tolerance: graceful degradation with failed elements

You already know

Step 4: random errors raise the floor as σ²/(ηt·N). Step 6: EIRP ∝ N², receive SNR ∝ N. A failed module is simply an element with weight zero, the largest possible amplitude error, but only on a few elements.

Definitions

Failed (dead) element: a module that neither transmits nor receives; its LNA contributes no noise. Stuck element: a module that keeps radiating with a wrong phase; it is worse, because it adds a full-amplitude random error instead of a missing one.

Failure fraction f: the share of failed elements. Graceful degradation: the property that an AESA keeps working, a little worse, as modules fail, instead of failing all at once like a single-transmitter radar.

Random, clustered and subarray failures: scattered independent failures; a run of neighbours (a shared cold-plate channel or connector); a whole subarray of 8 lost with its shared power supply or beamformer.

MTBF: mean time between failures of one module. With independent failures, the time until a fraction f has failed is t = −MTBF·ln(1 − f).

Losing elements costs gain in three different ways. On transmit, the field from (1 − f)·N PAs adds coherently, so the EIRP goes as (1 − f)²: 5 % failed is −0.45 dB. On receive, the missing elements take away signal as (1 − f)² but also their own noise as (1 − f), so the SNR falls only as (1 − f): −0.22 dB. And the missing weight scatters into a floor, exactly like the errors of Step 4, with σ² replaced by the failed fraction of the taper power. Where the failures are matters: random failures spread their error evenly; clustered or subarray failures form a large, structured hole in the aperture and raise near-in lobes much more.

EIRP ∝ (1 − f)²    receive SNR ∝ (1 − f)    floor ≈ Σfailed wn² / (Σworking wn)² ≈ f/((1 − f)²·ηt·N)    t = −MTBF·ln(1 − f)128 elements, −35 dB taper, 6 random failures (4.7 %): EIRP −0.42 dB, receive SNR −0.23 dB, floor −31.9 dB, peak sidelobe −25.5 dB (from −35.4 dB). With a module MTBF of 100 000 h, 4.7 % have failed after 4 800 h, about 6.6 months of continuous operation.

What goes wrong with the naive approach

The naive view counts only gain: 5 % failed costs 0.4 dB of EIRP, so the array can run until 20 % have failed. The sidelobes say otherwise: 6 random failures already lift the peak sidelobe from −35.4 to −25.5 dB, 6 clustered ones to −21.8 dB, and one lost subarray of 8 to −19.4 dB. If the sidelobe requirement is −30 dB, the array is out of specification after 2 % failures, long before the gain notices. The second naive assumption is that failures are always "off". A module that fails stuck on, with a random phase, is a full-amplitude error and costs more than a dead one; module control must make failures fail off.

c·(τ + tsw)/2: echoes from closer than this arrive before the receiver is ready.
Built-in calibration
A coupler network or mutual-coupling measurement that lets the array measure its own module errors in service.
Calibration table
Stored per-module corrections of phase and amplitude, often per frequency, temperature and state.
Circulator
A three-port ferrite device passing power PA → antenna → receiver; its isolation limits the leakage from PA to receiver.
Clipping (attenuator)
An element needing more attenuation than the range receives the maximum instead, flattening the taper.
Coherent combining
Adding N signals in phase: voltages add, power goes as N².
Common leg
The part of the module used by both transmit and receive: phase shifter, attenuator and their T/R switch.
Common-mode drift
The change shared by all modules over temperature; it alters the gain but not the pattern shape.
Cripps (load-line) model
A PA limited by maximum current and voltage gives full power only into Ropt: P/Popt = R (current-limited) or R/|Z|² (voltage-limited), with Z normalised to Ropt.
Duty cycle
The fraction of time the PA transmits.
EIRP of an array
N²·Pel·Gel/Lf: power per element times array gain.
Element gain Gel
4π·Acell/λ², π (4.97 dBi) for a λ/2 × λ/2 cell, falling as cos θ with scan.
Failure fraction f
The share of modules that have failed; EIRP goes as (1 − f)², receive SNR as (1 − f).
Grating-lobe onset
sin θg = λ/d − 1: the scan angle at which a second full beam appears.
G/T of an array
N·Gel/Tsys, with Tsys the noise temperature at one element.
Instantaneous bandwidth (IBW)
The band usable at once without the band edges losing too much gain; ≈ θ3/tan θ0 for phase shifters.
LSB
Least significant bit: the smallest step of a digital phase shifter (360°/2k) or attenuator.
MTBF, MTTF
Mean time between failures (of a module) and mean time to failure (of a device); with independent failures a fraction f has failed after −MTBF·ln(1 − f).
Mutual coupling
The part of one element's wave that arrives at another element's port.
PA gating
Switching the PA bias off between pulses so its output noise does not reach the receiver.
Peak sidelobe level (PSL)
The highest lobe outside the main beam, relative to the peak.
Probabilistic rounding
Rounding up with a probability equal to the fractional part; decorrelates the quantisation error at √2 times the rms.
Quantisation error
The difference between the required and the nearest available state; rms LSB/√12 if uniformly spread.
Quantisation lobe
A discrete sidelobe from a periodic quantisation error, about 1/22k.
Random phase offset
A known random phase per element added before rounding and removed in hardware, so the quantisation error becomes random.
REV method
Rotating element electric vector: stepping one element's phase while watching total power to find its amplitude and phase.
Scan blindness
An angle where |Γa| approaches 1 and the array radiates almost nothing.
State error
The deviation of each real phase-shifter state from its nominal value, given as rms over states.
Subarray TTD
A true time delay per group of M elements, with phase shifters inside each group.
T/R module
The electronics behind one element: transmit path, receive path, common leg and control.
T/R switching time
The time from the end of transmission until the receiver is usable.
Taper efficiency ηt
(Σw)²/(N·Σw²): the gain of a tapered array relative to uniform.
Taylor taper
A standard amplitude taper that holds the first n̄ − 1 sidelobes at a design level.
Thermal resistance θ
Temperature rise per watt from junction to cold plate.
Tracking
How closely modules follow each other over temperature: the rms spread of their drift per °C.
True time delay (TTD)
Steering by delays, whose phase grows with frequency, so the beam does not squint.
