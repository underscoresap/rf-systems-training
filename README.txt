RF Systems for Component Engineers - training pages
=====================================================

Open index.html: it is the welcome page. From there, Start leads to the system map and then through every guide in order (Previous / Next on every page); contents.html lists them all. Every page links to the others with local links,
so the whole folder works anywhere it is copied.

Contents
  index.html                      Welcome page (start here)
  system-map.html                 The whole system, clickable, with reading order
  contents.html                   All guides in reading order
  R1 to R6                        Radar basics: echo, antenna beam, detection and CFAR,
                                  pulse radar, FMCW, measuring targets
  A0                              Antenna fundamentals (deep dive)
  P3                              SAR imaging
  P4                              Listening receivers
  P5                              Recognising emitters
  M01 to M16 (no M13)             Component modules

Sharing on the office network from this PC
  1. Double-click Start-Training-Server.bat. It prints the link(s) to share,
     for example  http://192.168.1.76:8080/
  2. Keep that window open while people use the pages. Close it to stop sharing.
  3. The first time, Windows may ask whether to allow Python through the firewall:
     allow it on Private networks only.

Other ways to share
  - Copy the whole folder (or the zip) to a shared drive; people open index.html directly.
  - The pages need nothing installed. Fonts load from Google Fonts when online;
    offline they fall back to system fonts and still work.
