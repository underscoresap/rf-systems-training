Why we made this

Most of us work on one block at a time: an LNA, a filter, a synthesiser, a power amplifier, an ADC, some firmware. The specifications for that block arrive as numbers (noise figure, phase noise, P1dB, spurs, ENOB), but the reason for each number lives at system level: how far a radar can see, how small a target it can find, how fast a target it can measure, how weak a signal a receiver can hear. When that link is missing, it is hard to judge which spec really matters, which one can be relaxed, and what a failed spec will cost.

These guides build that link. They start from first principles, solve every equation with real numbers, and let you move the parameters yourself to see what changes.

How to go through it

First time: press Start, look at the system map, then follow the numbers. Each page has Previous and Next buttons at the top and bottom, so you can read it like a book. Part 1 first, because everything else builds on it. Guide 3 (antenna fundamentals) is a deep dive you can skip on a first pass.

Later: use the system map or the contents page to jump straight to the block you are working on.

Practical: the guides run in any modern browser, best on a laptop or desktop screen. Nothing needs to be installed. The example numbers are illustrative and general textbook material, not tied to any one product.
